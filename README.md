# Repositorio de Materiales: Probabilidades

Bienvenido al repositorio de materiales del curso. Aquí encontrarás el código fuente en LaTeX y la documentación estructurada para la página web.

## Contenido del Repositorio

- `main.tex`: Presentaciones y diapositivas compiladas en Beamer/LaTeX.
- `mkdocs.yml`: Archivo de configuración del sitio web.
- `docs/`: Archivos Markdown que generan las secciones de la página.
